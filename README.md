## ✔️Técnicas e tecnologias utilizadas

- `React`: Utilizado para a criação da interface de forma componentizada e dinâmica. Com ele, estruturamos toda a aplicação utilizando tanto Class Components quanto Function Components.

- `TypeScript`: Traz segurança e clareza no desenvolvimento com tipagem estática, além de facilitar a manutenção e escalabilidade do código.

- `SASS`: Um pré-processador CSS que facilita a escrita dos estilos com aninhamento, variáveis e reutilização de código.

- `CSS Modules`: Garante encapsulamento dos estilos por componente, evitando conflitos entre classes.

- `UUID`: Geração de identificadores únicos para controle de tarefas.

- `React Hooks`: Utilizados useState e useEffect para manipulação de estado e efeitos colaterais.

- `Props e Interfaces`: Para comunicação entre componentes e tipagem de dados no TypeScript.

🔨 Funcionalidades do projeto
<p align="justify"> ✅ Criar tarefas com nome e duração 
  ✅ Exibir lista de tarefas adicionadas 
  ✅ Selecionar uma tarefa para iniciar o cronômetro 
  ✅ Cronômetro funcional que inicia com o tempo da tarefa 
  ✅ Marcar tarefa como concluída ao finalizar o cronômetro 
  ✅ Estilização com SASS e organização de estilos com CSS Modules 
  ✅ Uso de props tipadas e componentes reutilizáveis 
  ✅ Componentização com SRP (Single Responsibility Principle) e DRY 
</p>
